We're using a SLAMTECH S2e Lidar. To connect to it, you'll need to be on the same network as it.

By default, its ip address is `192.168.11.2`, meaning your network adapter will have to have its ip set to `192.168.11.x`. 

To see the specific steps for your machine, check the [S2e user manual](https://bucket-download.slamtec.com/654b166e6da931c9a4ea110a4df22335f127379e/SLAMTEC_rplidarkit_usermanual_S2E_v1.1_en.pdf) pages 4 & 5.
