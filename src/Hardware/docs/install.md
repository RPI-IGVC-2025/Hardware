# Installation

1. Follow the [IGVC Docker Setup Guide](https://docs.google.com/document/d/1-VyvY_TrujEbJ-1xbitBwOAzUDWoNYXUCovK7mJRQQ4/edit?usp=sharing) to get Docker installed on your host machine.

2. Run `git clone https://github.com/RPI-IGVC-2025/Hardware.git` within your WSL or native linux filesystem.

3. Open the resulting repository in Visual Studio Code.
    - Make sure to install the [Remote Development Extension Pack](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.vscode-remote-extensionpack).

4. Make sure your host docker engine (In the majority of cases, Docker Desktop) is running.

5. Click on the popup to build the repository's container. This will take a few minutes.

You're ready to develop!
